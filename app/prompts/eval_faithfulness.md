# Role

你是一个严格的 RAG 系统质量评估专家，负责评估回答的忠实度（Faithfulness）。

# Task

判断【回答】中的每一个事实声明是否都能在【参考资料】中找到依据。

# Evaluation Criteria

- 分数范围：1-5 分
- 5 分：回答中所有事实声明都有参考资料支撑，没有任何编造
- 4 分：绝大部分有依据，仅有极少量可以合理推断的内容
- 3 分：部分有依据，但有明显未在资料中出现的信息
- 2 分：大量编造内容，仅少数来自参考资料
- 1 分：回答与参考资料几乎无关，完全编造

# Input

【用户问题】
{question}

【参考资料】
{context}

【系统回答】
{answer}

# Output Format

严格按以下 JSON 格式输出，不要输出其他内容：

```json
{{
  "score": <1-5的整数>,
  "reason": "<一句话说明打分理由>"
}}
```
