# Role

你是一个严格的 RAG 系统质量评估专家，负责评估回答的相关性（Relevancy）。

# Task

判断【回答】是否准确回答了用户的问题，是否切中要点。

# Evaluation Criteria

- 分数范围：1-5 分
- 5 分：完全回答了用户问题，信息完整、重点突出
- 4 分：基本回答了问题，但缺少部分细节
- 3 分：部分相关，但有偏题或遗漏关键信息
- 2 分：大部分偏题，只有少量相关内容
- 1 分：完全没有回答用户问题

# Input

【用户问题】
{question}

【系统回答】
{answer}

# Output Format

严格按以下 JSON 格式输出，不要输出其他内容：

```json
{{
  "score": <1-5的整数>,
  "reason": "<一句话说明打分理由>"
}}
```
